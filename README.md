# Apogee — Community & Issue Tracker

This is the public home for **Apogee for BookOrbit**, the iOS client for self-hosted
[BookOrbit](https://github.com/bookorbit) libraries — audiobooks, ebooks, and comics.

The app's source code is private. This repo is where testers and users get help,
report bugs, and follow development.

## Where to go

| I want to… | Go here |
|---|---|

| Report a reproducible bug | 🐛 [Issues](https://github.com/briarrrn/apogee-issues/issues/new) |

## Reporting a bug

Open an [issue](https://github.com/briarrrn/apogee-issues/issues/new) and include:

- **Device & iOS version** (e.g. iPhone 17 Pro, iOS 27.0)
- **Server setup** (BookOrbit version, local/Tailscale/remote, reverse proxy if any)
- **Steps to reproduce** — what you did, what you expected, what happened
- Screenshots/screen recordings welcome

Not sure it's a bug? Start a [discussion](https://github.com/briarrrn/apogee-issues/discussions)
instead — I'll convert it to an issue if it turns out to be one.

## Following development

Day-to-day work happens in the private repo. When a fix or feature ships to
TestFlight, I crosspost it here so you can see what changed and confirm the fix.
Watch this repo (👁 Watch → All Activity) to get notified.
